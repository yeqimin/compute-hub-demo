# Task 13 异步任务中心报告

## 交付内容

- 基于 `GET /tasks` 的服务端筛选、白名单排序、分页和 URL 查询恢复：平台管理员可按租户筛选；操作、状态、命令号、实例号与起止时间对所有可见用户可用。
- 任务列表展示任务号、可跳转的实例号、操作、状态、自动/人工重试、错误与时间；提供加载、空列表和可重试错误提示。
- 指标卡明确区分服务端返回的“当前筛选总任务”和当前页的处理中、成功、异常/待对账数量，不虚构跨页状态统计。
- 详情抽屉读取 `GET /tasks/{id}`，展示任务、命令、消息、Outbox、重试、错误与时间；缺失字段显示 `-` 或“尚未到达”。五阶段时间线为：事务、数据库 Outbox、gRPC 引擎、回调、业务收敛。
- `UNKNOWN` 且拥有 `instance:retry` 权限时显示“重新投递”和“人工对账”，分别调用 `POST /tasks/{id}/retry` 与 `POST /tasks/{id}/reconcile`。两项操作均需确认；失败时显示 ApiError 的 traceId。VIEWER 仅可查看。未实现且未展示 redrive。
- 页面每 5 秒轮询；用户编辑筛选、详情抽屉开启或处置提交中不会轮询，卸载会清除定时器。

## 风险

- 后端详情当前直接提供 Outbox 和引擎/回调字段；前端按字段存在性进行降级展示。若后端未来拆分为嵌套对象，需要同步适配字段映射。
- 当前需求明确不接 SSE、RabbitMQ/DLQ 或 redrive，因此更新依赖 5 秒轮询。

- 日期范围控件改为由筛选状态驱动：初始 URL、浏览器导航与重置均可回填或清空控件；控件选择后会随查询写入 URL 和请求参数。路由回填仅更新本地筛选并加载数据，不会再次写 URL。
- “本页异常 / 待对账”现在统计当前页 `FAILED`、`DEAD`、`UNKNOWN` 三种终态/待核对状态，继续明确保持当前页口径。
